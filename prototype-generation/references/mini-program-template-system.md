# 小程序原型固定模板体系

本文件用于小程序/企业微信小程序 HTML 原型生成。它不是业务需求文档，而是页面模板和组件模板库。生成小程序原型时，先选择页面模板，再组合组件模板；不要临时拼 PC 查询栏、表格或不稳定卡片。

## 使用顺序

1. 先确认终端为小程序或企业微信小程序。
2. 读取 `mobile-ui-interaction.md`、`mini-program-ui-interaction.md` 和本文件。
3. 为每个小程序页面选择一个页面模板编号。
4. 页面内容只允许使用本文件组件模板组合；确有特殊业务需要时，在不破坏手机布局的前提下扩展。
5. 输出原型说明时记录每个小程序页面采用的模板编号。

本模板体系不要求截图验收。完成时做结构自检：页面是否使用了模板、组件是否全宽稳定、触控区是否不小于 44px、底部操作是否避开安全区、是否没有 PC 表格/查询栏压缩痕迹。

## 基础布局

所有小程序 HTML 原型必须有稳定手机容器：

- `mp-phone`: 375/390px 手机视口，包含状态栏、导航栏、内容区、TabBar 或安全区。
- `mp-nav`: 顶部导航，标题单行，右侧预留微信胶囊区，不把关键按钮放到胶囊附近。
- `mp-content`: 内容区，左右 padding 12-16px，滚动区域独立。
- `mp-tabbar`: 3-5 个一级入口，图标+文字，当前项主色高亮。
- `mp-safe-bottom`: 底部安全区。

CSS 硬约束：

- 所有卡片、Cell、列表项、底部按钮容器必须 `width: 100%` 和 `box-sizing: border-box`。
- 所有高频按钮高度不小于 48px，普通可点击项不小于 44px。
- 不使用 inline 自适应宽度 button 作为卡片。
- 不在手机端使用 PC 表格、PC 查询栏、左右分栏、密集多列字段。

## 页面模板

### MP-PAGE-LOGIN 手机号登录/授权

适用：手机号登录、微信/企微授权、身份初始化。

结构：

- 顶部品牌/系统名。
- 手机号输入或授权按钮。
- 验证码输入和发送验证码按钮。
- 主按钮：登录/进入。
- 辅助说明：内部系统、授权范围、隐私提示。
- 结果反馈：Toast/Dialog。

禁止：默认出现修改密码入口；除非需求明确账号密码登录。

### MP-PAGE-ROLE 角色选择

适用：一人多角色、原型演示不同身份。

结构：

- 页面标题和当前手机号/组织提示。
- `mp-cell-card` 角色卡片列表。
- 每个角色显示角色名、数据范围、主要工作说明。
- 点击进入对应首页。

### MP-PAGE-WORKBENCH 首页/工作台

适用：首页、任务台、个人工作概览。

结构：

- `mp-hero-summary`: 当前角色、今日重点、关键提醒。
- `mp-metric-grid`: 2-4 个核心指标。
- `mp-quick-grid`: 3-8 个快捷入口。
- `mp-reminder-list`: 待办、通知、预警。

首页必须是当前用户工作台，不是 PC 统计仪表盘缩小版。

### MP-PAGE-LIST 列表/检索

适用：线索列表、任务列表、通知列表、记录列表。

固定结构：

```html
<section class="mp-search-row">
  <div class="mp-search"><i></i><input placeholder="搜索关键词"></div>
  <button class="mp-filter"><i></i><span>筛选</span></button>
</section>
<section class="mp-list">
  <button class="mp-list-card">...</button>
</section>
<div class="mp-bottom-action">
  <button class="mp-primary">新增/提交/处理</button>
</div>
```

列表卡片结构：

- 第一行：主标题、编号/辅助标识、状态标签。
- 第二块：2-4 个摘要字段，优先 2 列栅格。
- 第三块可选：更新时间、责任人、下一步动作。

硬约束：

- `mp-search-row` 使用 `grid-template-columns: minmax(0, 1fr) auto`。
- `mp-filter` 宽度建议 64-88px，文字不得竖排。
- `mp-list-card` 必须全宽、稳定内边距、可点击反馈。
- 列表主操作放在底部安全区内 sticky/fixed 容器；不得遮挡最后一项。

### MP-PAGE-DETAIL 详情

适用：业务对象详情、任务详情、通知详情。

结构：

- `mp-detail-head`: 标题、状态、关键编号。
- `mp-section`: 基础信息，2 列轻量字段或 Cell。
- `mp-section`: 业务摘要/进度/关联记录。
- `mp-timeline`: 操作记录、流程记录、跟进记录。
- `mp-bottom-action`: 处理、编辑、复制、返回等。

详情页操作优先放底部，次要操作可放更多 ActionSheet。

### MP-PAGE-FORM 录入/更新表单

适用：新增、编辑、提报、信息维护。

结构：

- 分组表单 `mp-form-section`。
- 字段使用 `mp-field`，选择项使用 Picker 风格 Cell。
- 长表单拆分为分组或步骤。
- 底部主按钮：保存/提交。
- 离开未保存内容需 Dialog。

禁止：一页堆满未分组字段；使用 PC 两列/三列表单。

### MP-PAGE-ACTION 审批/处理

适用：审批、驳回、转办、状态更新。

结构：

- 业务摘要卡片。
- 当前节点/处理要求。
- 意见输入。
- 附件/备注可选。
- 底部并列主次按钮：通过/驳回/转办。
- 操作后结果页或 Toast。

### MP-PAGE-MESSAGE 消息/通知

适用：消息中心、通知提醒、抄送消息。

结构：

- 顶部分类 Tab：全部/待办/通知/系统等。
- 消息 Cell/List：标题、来源、时间、已读状态。
- 点击进入详情或跳转业务对象。
- 支持标记已读、清空已读等轻量操作。

### MP-PAGE-MINE 我的/个人中心

适用：我的、个人资料、账号菜单。

结构：

- 顶部个人卡：姓名/角色/部门或组织。
- `mp-cell-group`: 个人资料、我的手机号、帮助反馈、切换身份、退出登录。
- 手机号登录场景下不默认生成修改密码。
- 不默认生成帮助与服务状态；除非需求确认需要授权状态、弱网诊断或服务状态。
- 点击菜单优先 BottomSheet/ActionSheet；复杂资料进入独立页面。

### MP-PAGE-RESULT 结果/空状态/无权限

适用：提交结果、空列表、失败、无权限。

结构：

- 结果图标/状态标题。
- 业务解释。
- 下一步按钮：返回列表、继续新增、查看详情、联系管理员。

## 组件模板

### mp-search-row / mp-search / mp-filter

用于列表页顶部。搜索框近全宽，筛选按钮独立。不得把筛选做成 PC 文字按钮塞进搜索框。

### mp-list-card

用于业务对象列表项。必须是全宽块级元素，可用 `button`，但必须设置 `display: grid|block`、`width: 100%`、`text-align: left`。

### mp-cell-group / mp-cell

用于我的页、设置页、详情字段。Cell 高度不小于 56px，左图标可选，中间标题+说明，右侧箭头或状态。

### mp-status-tag

状态必须有文字。默认色：信息蓝/青、成功绿、警告黄、失败红、中性灰。不能只靠颜色表达状态。

### mp-metric-grid

用于首页或详情摘要。2-4 项，数字突出，说明文字短。

### mp-bottom-action

用于底部主操作。sticky 或 fixed，底部留安全区，不遮挡内容。单按钮全宽；双按钮用主次关系，不超过两个高频按钮。

### mp-bottom-sheet / mp-action-sheet

用于筛选、更多操作、原因选择、轻量表单。必须限制在手机容器内，顶部 handle，最大高度 70%-75%。

### mp-dialog / mp-toast

Dialog 用于高风险确认或离开未保存提示；Toast 用于轻量成功/失败反馈。

## 生成禁令

- 不得把 PC 管理后台的查询栏、表格、左右分栏、抽屉菜单直接迁移到小程序。
- 不得为每个页面临时发明不同卡片结构；先复用模板，再做业务字段替换。
- 不得让列表卡片宽度随内容变化。
- 不得让“筛选”“新增”“更多”等短按钮文字竖排或被挤压。
- 不得把底部主按钮贴到安全区外或遮挡最后一条列表。
- 不得在手机号登录小程序中默认生成修改密码。
