# 组卷后质检清单

## 必检项

- 总报告一级标题数量、顺序和文本是否等于用户提供清单。
- 如果用户未提供映射关系，是否已先从目录页读取 Heading 1-4 目录树，并按同名文件自动挂接章节和附件。
- 自动匹配时，是否已清理目录标题和文件名中的 `一、`、`（一）`、`1.`、`1.1.` 等编号前缀。
- 一级标题无同名文件但有下级目录时，是否作为目录型标题保留，例如 `附件`。
- PDF 附件是否按页渲染为图片并插入，是否使用缓存，图片是否居中。
- 是否存在未匹配或多候选的章节/附件文件；如有，应停止并提示，而不是猜测挂接。
- 分页/章节文件中的重复一级标题是否已删除。
- 子章节标题是否按规则保留或降级。
- 二级、三级、四级标题编号是否符合总报告统一规范。
- Heading 1-4 是否使用真实 Word 标题样式，而不是手工加粗字号。
- 正文是否使用 Normal 样式或等效正文样式。
- 正文 run 是否统一为规定字体、字号、非加粗、无斜体、无下划线、无异常颜色、无残留字符样式；图表题注可按规范保留加粗。
- 正文是否误识别为标题。
- 表格是否整体居中，是否按表头画像套用了表格宽度、列宽、边框、首行重复、单元格边距和垂直居中。
- 表格中文字字号、字体、加粗和行距是否符合格式规范。
- 图片是否为内嵌图片，宽度是否符合格式规范，图片所在段落是否居中。
- 图题是否统一为规定字体、字号、加粗和居中；图题前是否已清理普通空格、Tab、全角空格等前导空白。
- 是否存在连续空行、多余空段、尾部空白页或空段里的手工分页符。
- 是否能导出 PDF；PDF 页数是否合理，末页是否有正文内容。
- 覆盖输出时是否只保留一个原始备份；除非用户明确要求，不应每次重跑都生成新的 backup。
- 组卷规则、字体规则、空行规则和备份规则如被用户修订，应同步更新到 Skill 或脚本中，避免下次重复犯同类问题。

## 审计输出

审计结果至少包含：

- 输出文件路径；
- 备份文件路径；
- 一级标题清单与数量；
- 各级标题数量；
- 段落、表格、图片数量；
- 格式违规数量；
- 图片段落居中检查结果；
- 图题前导空白清理结果；
- 表格画像、列宽、边框和表格文字检查结果；
- PDF 附件页数、缓存目录和插入图片数量；
- 是否清理尾部空白页；
- PDF 页数或无法导出的原因；
- 未自动修复的问题。

如果环境缺少 LibreOffice/Word 渲染能力，应明确说明未完成逐页视觉渲染，但仍要完成结构和 OOXML/样式审计。
