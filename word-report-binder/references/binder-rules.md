# 组卷规则

## 结构来源

最终报告结构优先以目录页/母版文件中的一级标题顺序为准。目录页不仅提供样式、版心和初始结构，也可以作为默认的章节结构来源。

如果用户未显式提供章节映射关系，应按以下方式自动组卷：

1. 先打开目录页/母版文件，按 Word Heading 1-4 或 `一、...`、`（一）...`、`1. ...`、`1.1. ...` 形式读取目录树；
2. 清理各级标题前缀编号，得到目录节点名称；
3. 在目录页所在目录或用户指定章节目录中查找同名 `.docx`、`.pdf`、`.png`、`.jpg`、`.jpeg` 文件；
4. 文件名清理编号和扩展名后，与目录节点名称一致，即认为匹配；
5. 按目录页顺序挂接章节和附件文件，不再要求用户逐一写明映射关系；
6. 目录节点一旦匹配到同名源文件，即以该文件为完整内容来源，默认不再继续处理该节点下级目录，避免组卷后的完整报告被二次拆解；
7. 一级标题节点优先匹配同名 `.docx` 正文章节；如果一级标题没有同名文件但有下级目录，则保留为目录型标题，例如 `附件`；
8. 二级、三级、四级节点可匹配 Word、PDF 或图片附件；
9. 如果某个叶子目录项找不到同名文件，或存在多个同名候选文件，应停止并提示缺失或歧义文件。

用户显式提供一级标题清单或章节映射时，以用户提供的清单/映射为准。

## 标题映射

合并时按每个分页/章节文件的首个有效标题判断：

| 情况 | 处理 |
| --- | --- |
| 分页首个一级标题与目标一级标题一致或语义一致 | 删除该重复一级标题；其下二级、三级、四级标题按原级别进入总报告 |
| 分页首个一级标题不是目标一级标题，而是子章节标题 | 该一级标题降为二级标题；其下标题依次降级 |
| 分页没有一级标题 | 按目标一级标题下的正文内容插入；现有二级以下标题保持级别 |
| 分页标题级别混乱 | 按标题文本语义和总报告目录规则重新映射 |

## 编号规范

默认中文验收/绩效报告标题编号体系：

- 一级标题：`一、`、`二、`、`三、`
- 二级标题：`（一）`、`（二）`、`（三）`
- 三级标题：`1.`、`2.`、`3.`
- 四级标题：`1.1.`、`1.2.`、`2.1.`

如果用户或项目格式规范提供了不同编号体系，以用户或项目格式规范为准。

合并后要检查编号是否统一。分页文件中的编号不符合总报告规范时，应改为目录页统一规范。不要只保留来源文件的局部编号。

## 内容保留边界

原则上不改写章节正文、表格内容和图片内容。允许自动处理：

- 重复标题删除；
- 标题级别映射；
- 标题编号规范化；
- 样式统一；
- 空行、尾部空白页、异常分页清理；
- 图题、图片尺寸、图片所在段落居中、表格文字和表格版式格式化。

涉及事实、金额、指标、附件编号、页码证据时，不应无依据改写。

## 附件与 PDF

附件目录建议在目录页中预设到需要控制顺序的层级：

```text
五、附件
（一）项目立项与任务书类附件
1. 项目任务书
2. 预算调整备案材料
```

对应文件可以放在目录页同目录或附件子目录下：

```text
附件/项目立项与任务书类附件/项目任务书.pdf
附件/项目立项与任务书类附件/预算调整备案材料.docx
```

PDF 附件处理规则：

- 按页渲染为图片后插入 Word，不改写 PDF 内容；
- 每页图片居中，宽度按格式规范统一；
- 渲染图片按 PDF 文件哈希缓存，PDF 未变化时复用缓存；
- PDF 文件变化时重新渲染；
- 缓存目录默认使用输出文件所在目录下的 `.binder-cache/pdf-pages/`。
- 执行 PDF 附件组卷时，优先使用 Codex 捆绑 Python 运行脚本；脚本支持 PyMuPDF 或 pypdfium2 两类渲染后端。

## 图片与表格

组卷成功后的 Word 中，所有内嵌图片所在段落必须居中，不能只调整图片宽度。图题按格式规范保持居中。

图题段落必须先清理前导空格、Tab 和全角空格，再设置居中。例如 ` 图1 前列腺癌专病患者管理平台业务架构图`、`　图2 前列腺癌专病患者管理平台技术架构图` 应识别为图题，清理为 `图1 ...` / `图2 ...` 后居中，避免前导空格造成视觉不居中。

表格处理不能只统一字体。应根据格式规范或参考报告提取出的表头特征识别表格类型，并统一设置：

- 表格整体居中；
- 表格宽度与列宽；
- 边框样式和线宽；
- 首行作为重复标题行；
- 单元格上下左右边距；
- 单元格垂直居中；
- 表格内文字字体、字号、加粗、行距。

如格式规范中已提取出具体表格画像，应优先套用画像；无法匹配画像的表格，再使用通用表格规则。
